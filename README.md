This project was intended as practice in three main areas: using windows functions to quickly analyze data, transforming poorly formatted date data into a usable format for querying, and creating clear logic steps by chaining multiple CTEs. 
The data used for this project was the 2026 NJ Incarcerated Census. 

Click the following link for more information: https://data.nj.gov/Public-Safety/NJDOC-Incarcerated-Persons-Census/237p-gehp/about_data

The CSV file titled “Dates” was created myself only for practice and has no association with existing incarcerated individuals.
